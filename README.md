# Описание
Pineapple Price List (PPL) - это сайт типа имиджборд. Сайт позволит пользователям создавать свои доски и треды. Анонимность пользователей обеспечивает регистрация по имени-паролю, никакой дополнительной информации. Сайт позволяет прекреплять к постам файлы любого типа, а также поддерживает цепочки ответов.

# Техническое задание
### Обзор проекта
При заходе на сайт пользователю предлогается выбрать доску. Незарегистрированный пользователь может читать все доски и треды, но для создания собственных - требуется регистрация. Регистрация происходит по логину+паролю.
### Реализация постов
Каждый пост имеет уникальный id и является ответом на другой пост. Пост состоит из текста (обязательно), картинки и прикреплённого файла (опционально).
### Реализация БД
БД состоит из трёх таблиц:
- __users__ - Имя (primary key), описание, картинка, пароль.
- __boards__ - Название (primary key), описание, картинка, дата создания, кем создана (foreign key).
- __posts__ - На что явл. ответом (primary key), id, текст поста, картинка, ссылка на прикреплённый файл, дата создания, на какой доске (foreigh key), кем создан (foreign key).

# Пояснительная записка
### Название проекта
Pineapple Price List (PPL)

### Описание идеи
Сайт типа имиджборд, но с возможностью регистрации пользователя. Ещё одна особенность - пользователи могут сами создавать доски. Анонимность достигается за счёт регистрации, не требующей никакой информации помимо логина и пароля.
### Описание реализации
При заходе на сайт пользователя встречает главная страница с выбором доски. Пользователь может войти в свой аккаунт или зарегистрировать новый. Незарегистрированные пользователи могут просматривать все посты и доски, но не могут создавать свои. Пост являться ответом на доску или на другой пост.

Основные классы:
- __board__ - Объект доски в таблице.
- __post__ - Объект поста в таблице.
- __user__ - Объект пользователя в таблице.
### Описание технологий
Данный проект использует билиотеки Flask, flask_wtf, sqlalchemy, werkzeug.
